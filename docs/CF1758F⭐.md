[Decent Division - CodeForces 1758F - Virtual Judge](https://vjudge.net/problem/CodeForces-1758F)
+ 建模：考虑令 $0$ 为 $-1$，$1$ 为 $+1$，此时能得到一个折线。于是我们可以将选择一些区间，变成在折线上画出一些水平的线，使得所有的上升段都被包含。特别的，因为串的长度很大且初始全为 $0$，我们强行令其经过 $(0,0)$。
+ 我们定义：
	+ 谷底：对于任意子串 ```01``` 中 ```0``` 代表的折线上的点。
	+ 峰顶：对于任意子串 ```10``` 中 ```1``` 代表的折线上的点。
	+ 极长上升段：极长  ```1``` 段代表的折线上的段。
	+ 极长上升段 $u-v$：开头高度为 $u$，结尾高度为 $v$。
+ 一个显然错误的做法：从每个“谷底”开始，往右延伸直到与折线相交。此时我们显然能构造出一个反例：
	假设初始谷底为 $(x,0)$，然后后面的所有谷底都形如 $(?,1)$。此时我们对于 $x+1$ 进行反转，此时不难发现我们操作数为 $O(\texttt{谷底})$ 的。每次一个区间的谷底都会造成影响。
+ 我们发现：
	+ 我们首先只用了一边的无穷多的 $0$。能不能往左延伸。即从峰顶开始延伸？（x）
	+ 能不能只在相邻两个上升段之间操作。（x）
	+ 如何修正使得上面的情况合法：我们发现只需要定义不能交在谷底即可，此时发现影响就变成 $O(1)$ 的了。
